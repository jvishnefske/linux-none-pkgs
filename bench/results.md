# linux-none against musl and glibc

The same sources, features and release profiles, built three ways:
linux-none-pkgs' builder (std on `x86_64-unknown-linux-none`),
nixpkgs' `pkgsStatic` (musl, static) and nixpkgs (glibc, dynamic).
Generated by `nix run .#bench` on 2026-11-16:
QEMU Virtual CPU version 2.5+, 18 CPUs, Linux 7.0.0-31-generic.

- **Size**: the stripped executable (for glibc, without the shared libraries it loads).
- **Start**: `--version` (payload-sim: one tick), mean of 200 runs.
- **Peak RSS**: of the workload (GNU time; the server: VmHWM after the load).
- **Syscalls**: distinct / total, from `strace -f` over the workload (the server: 2,000 requests).
